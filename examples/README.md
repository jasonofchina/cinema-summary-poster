# Examples（示例海报）

此目录用于存放正例和反例海报样本，供 Skill 执行时参照。当前为空占位，后续请按以下清单补充：

## 待补充素材清单

### good-poster.png
- 用途：符合所有质量标准的正例海报
- 要求：文字清晰无乱码、风格贴合影片、排版层次分明、纸张材质与风格统一
- 数量：至少 3 张，覆盖不同影片类型（古装/科幻/文艺各一）
- 示例片名：《星尘回响》《墨城纪事》《雾岛恋曲》（均为虚构）

### bad-poster.png
- 用途：展示常见问题的反例海报
- 要求：标注具体问题（如文字乱码、风格冲突、排版拥挤、水印遮挡等）
- 数量：至少 2 张

### good-poster-notes.md（可选）
- 用途：对正例海报的设计决策说明
- 内容：每张正例对应的风格选择理由、字体搭配逻辑、构图思路

📌 补充完成后请同步更新 SKILL.md 中 Additional resources 的引用路径。
