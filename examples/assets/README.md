# Assets（素材资源）

此目录用于存放 Skill 执行时直接调用的素材文件。当前为空占位，后续请按以下清单补充：

## 待补充素材清单

### paper-textures/
- 用途：背景纸张纹理素材
- 要求：透明底 PNG 或高分辨率 JPG，至少包含羊皮纸、宣纸、牛皮纸、水彩纸、素描纸、铜版纸 6 种
- 命名规范：{纸张类型}-{色调}.png，如 xuan-paper-warm.png

### watermark-template.png
- 用途：通用水印模板
- 要求：透明底 PNG，浅灰/浅蓝双色版本，尺寸 200x200px 以上

### fonts/（可选）
- 用途：特殊字体文件
- 要求：开源可商用字体，WOFF2 或 TTF 格式
- 命名规范：{字体名}-{字重}.ttf

### color-swatches.png（可选）
- 用途：配色方案速查图
- 要求：按影片类型分组的色卡图

📌 补充完成后请同步更新 SKILL.md 中 Additional resources 的引用路径。
