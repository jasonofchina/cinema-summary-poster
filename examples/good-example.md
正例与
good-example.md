## Positive Example 1: Sci-fi "Stardust Echo" / 正面范例 1：科幻片《星尘回响》

### Basic Info / 基本信息
- Genre / 类型: Sci-fi / Cyberpunk / 科幻/赛博朋克
- Aspect Ratio / 画幅: 3:4 Portrait / 竖版
- Core Content / 核心信息: Title + Quote + Theme + Rating / 片名+台词+主旨+评分

### Visual Description / 画面描述
- Background: Deep blue solid electronic bg, no paper texture, no code rain. / 深蓝色纯色电子背景，无纸纹，无代码雨。
- Subject: Minimalist spaceship silhouette, centered lower third. / 极简风格飞船剪影，居中偏下。
- Palette: Deep blue primary, neon purple accent, silver gray secondary. / 深蓝为主，霓虹紫点缀，银灰辅助。

### Texture & Style / 质感与风格
- 3D render with metallic sheen. / 3D 渲染风格，表面有金属光泽。
- No decorative clutter; clean composition. / 无多余装饰元素，画面干净。

### Text Hierarchy / 文字分层
| Level / 层级 | Content / 内容 | Font / 字体 | Position / 位置 |
| :--- | :--- | :--- | :--- |
| Main Title / 主标题 | 星尘回响 Stardust Echo | Songti + Sans-serif | Top 1/3, centered / 上方居中 |
| Subtitle / 副标题 | "We're not searching for home; we're searching for ourselves." / "我们不是在寻找家园，是在寻找自己。" | Songti / 宋体 | Below title / 主标题下方 |
| Body / 正文 | Douban 8.7 / IMDb 8.2 | Kaiti / 楷体 | Bottom 1/3 / 下方 |
| Annotation / 注释 | 2026 · Sci-fi / 科幻 | Songti Light / 宋体 Light | Bottom-right / 右下角 |

### Key Takeaways / 要点总结
- ✅ Minimal background, no tech element clutter. / 背景极简，没有堆砌科技元素。
- ✅ Clear text hierarchy; title and quote instantly visible. / 文字层级清晰。
- ✅ Unified color palette, no jarring colors. / 色调统一，没有突兀颜色。

## Positive Example 2: Period Drama "Ink City Chronicles" / 正面范例 2：古装片《墨城纪事》

### Basic Info / 基本信息
- Genre / 类型: Period / Epic / 古装/史诗
- Aspect Ratio / 画幅: 3:4 Portrait / 竖版
- Core Content / 核心信息: Title + Quote + Theme + Awards / 片名+台词+主旨+获奖记录

### Visual Description / 画面描述
- Background: Xuan paper texture, warm gold + ochre red palette. / 宣纸纹理，暖金与赭红为主色调。
- Subject: Back-facing figure in period costume on city wall, overlooking distance. / 古装背影人物站在城墙上俯瞰远方。
- Texture: Film grain + oil brushstroke. / 胶片颗粒+油画笔触。

### Texture & Style / 质感与风格
- Film grain with subtle vignette. / 胶片质感，边缘轻微暗角。
- Clear character outline, natural details. / 人物轮廓清晰，细节自然。

### Text Hierarchy / 文字分层
| Level / 层级 | Content / 内容 | Font / 字体 | Position / 位置 |
| :--- | :--- | :--- | :--- |
| Main Title / 主标题 | 墨城纪事 Ink City Chronicles | Songti Bold / 宋体 Bold | Top, centered / 上方居中 |
| Subtitle / 副标题 | "As long as the city stands, we stand." / "城在人在，城破人亡。" | Songti / 宋体 | Below title / 主标题下方 |
| Body / 正文 | 45th HKFA Best Film / 第45届金像奖最佳影片 | Kaiti / 楷体 | Bottom / 下方 |
| Annotation / 注释 | 2026 · Period / Epic / 古装/史诗 | Songti Light / 宋体 Light | Bottom-left / 左下角 |

### Key Takeaways / 要点总结
- ✅ Xuan paper texture perfectly matches period genre. / 宣纸纹理与古装风格完美融合。
- ✅ Back-facing composition leaves ample whitespace. / 人物背影构图留白充足。
- ✅ Award info in Kaiti creates clear hierarchy vs. quote. / 获奖记录用楷体，与台词形成层级差异。

## Pitfall Checklist / 反面提醒清单

| # | Error Type / 错误类型 | Symptom / 具体表现 | Fix / 正确做法 |
| :--- | :--- | :--- | :--- |
| 1 | Garbled Text / 文字乱码 | Unknown characters, missing strokes / 不认识的字符、缺笔画 | Regenerate immediately or post-process text / 立即重新生成或后期叠字 |
| 2 | Element Clutter / 元素堆砌 | >10 elements in frame / 画面塞了10个以上元素 | Max 5 subjects, ≥20% whitespace / 主体≤5个，留白≥20% |
| 3 | Text Obscures Subject / 文字遮挡主体 | Quote overlaid on character face / 台词压在人物脸上 | Reposition text or simplify background / 调整文字位置或降低背景复杂度 |
| 4 | Real Human Face / 生成真人脸 | AI generates real celebrity likeness / AI生成真实明星脸 | Use stylized/illustrated treatment / 改用风格化/插画化处理 |
| 5 | Style Conflict / 风格冲突 | Period drama with Xuan paper bg / 科幻片用了宣纸背景 | Follow style-guide.md strictly / 严格按 style-guide.md 匹配 |
| 6 | Font Chaos / 字体混乱 | 5+ fonts on one poster / 同一张海报用5种字体 | Max 3: Songti title, Kaiti body, Songti annotation / 最多3种 |
| 7 | Jarring Color / 色彩突兀 | Neon green in period drama / 古装片出现荧光绿 | Use color palette from style-guide.md / 按色卡选色 |
| 8 | Oversized Watermark / 水印过大 | Watermark covers 30% of frame / 水印占画面30% | ≤10%, centered, single watermark / 占比≤10%，居中，单水印 |
